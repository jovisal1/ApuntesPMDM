Para trabajar con Flutter y desarrollar aplicaciones para Android, necesitaremos disponer de un **entorno de desarrollo correctamente configurado**. A lo largo de los siguientes apartados instalaremos y configuraremos las herramientas necesarias:

* **Flutter SDK**: un **SDK (*****Software Development Kit*****)** es un conjunto de herramientas, bibliotecas y utilidades que facilita el desarrollo de aplicaciones para una determinada tecnología o plataforma. El SDK de Flutter será la pieza central de nuestro entorno y nos permitirá **crear, ejecutar, depurar y compilar** nuestros proyectos.
* **Android Studio y SDK de Android**: instalaremos Android Studio principalmente para disponer y gestionar el **SDK de Android y sus herramientas asociadas**, necesarias para compilar y ejecutar nuestras aplicaciones en dispositivos Android.
* **Visual Studio Code**: será el **editor de código principal** que utilizaremos durante el curso. Lo configuraremos con las extensiones de **Flutter y Dart** para facilitar el desarrollo, la ejecución y la depuración de nuestras aplicaciones.
* **Emuladores de Android**: configuraremos dispositivos virtuales que nos permitirán **ejecutar y probar nuestras aplicaciones** sin necesidad de utilizar un dispositivo físico. Para ello podremos utilizar los emuladores proporcionados por Android Studio y, cuando sea necesario, herramientas como **Genymotion**.

Una vez configurados estos componentes, tendremos preparado nuestro entorno para comenzar a desarrollar y probar aplicaciones Flutter sobre Android.
