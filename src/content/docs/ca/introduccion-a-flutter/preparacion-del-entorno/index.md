Per a treballar amb Flutter i desenvolupar aplicacions per a Android, necessitarem disposar d'un **entorn de desenvolupament correctament configurat**. Al llarg dels següents apartats instal·larem i configurarem les eines necessàries:

* **Flutter SDK**: un **SDK (*****Programari Development Kit*****)** és un conjunt d'eines, biblioteques i utilitats que facilita el desenvolupament d'aplicacions per a una determinada tecnologia o plataforma. El SDK de Flutter serà la peça central del nostre entorn i ens permetrà **crear, executar, depurar i compilar** els nostres projectes.
* **Android Studio i SDK d'Android**: instal·larem Android Studio principalment per a disposar i gestionar el **SDK d'Android i les seues eines associades**, necessàries per a compilar i executar les nostres aplicacions en dispositius Android.
* **Visual Studio Code**: serà el **editor de codi principal** que utilitzarem durant el curs. El configurarem amb les extensions de **Flutter i Dart** per a facilitar el desenvolupament, l'execució i la depuració de les nostres aplicacions.
* **Emuladors d'Android**: configurarem dispositius virtuals que ens permetran **executar i provar les nostres aplicacions** sense necessitat d'utilitzar un dispositiu físic. Per a això podrem utilitzar els emuladors proporcionats per Android Studio i, quan siga necessari, eines com **Genymotion**.

Una vegada configurats estos components, tindrem preparat el nostre entorn per a començar a desenvolupar i provar aplicacions Flutter sobre Android.
